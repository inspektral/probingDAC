# probingDAC

This repository contains the code for the probingDAC project. The probingDAC project is a series of experiments on the descript audio codec latent space.

## Installation

To install the required packages, run the following command:

```bash
pip install -r requirements.txt
```

## Usage

To run the probingDAC experiments, just run all the cells in the `probingDAC.ipynb` notebook.
